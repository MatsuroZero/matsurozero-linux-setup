                🧰 Agent abilities and all provided tools (19)
                

                    
get_system_statusReads live CPU, RAM, disk space, operating system, hostname, and uptime.

                    
list_appsLists launchable desktop apps and their exact IDs.

                    
open_appLaunches an installed app using an ID returned by list_apps.

                    
list_windowsLists open Hyprland windows with title, app class, workspace, focus state, and address.

                    
list_wallpapersLists wallpaper names and file paths from Serpantinum's existing wallpaper index.

                    
list_processesLists current user processes with PID, name, CPU use, and RAM use.

                    
focus_windowFocuses a window by its address from list_windows.

                    
switch_workspaceSwitches Hyprland to workspace 1 through 10.

                    
media_controlPlays/pauses media or skips to the next/previous track.

                    
press_shortcutSends one of the predefined keyboard shortcuts, such as Alt+Tab, Super+D, Ctrl+C, or Ctrl+V.

                    
set_wallpaperSets a wallpaper from the indexed wallpaper list; asks for confirmation.

                    
type_textTypes literal text into the focused app; asks for confirmation and is not for commands.

                    
close_windowCloses a window by its listed address; asks for confirmation.

                    
click_atClicks a supplied screen coordinate; asks for confirmation and cannot visually inspect the screen.

                    
terminate_processRequests termination of a process by PID, with protected processes blocked and confirmation required.

                    
package_actionUpdates, reinstalls, or uninstalls an already-installed pacman package; asks for confirmation and does not install new packages.

                    
control_ollama_serviceStarts or stops the Ollama system service; may open a local terminal for sudo authorization.

                    
reload_serpantinumRuns the configured Serpantinum reload script; asks for confirmation.

                    
run_shell_commandRuns a general Bash command as the dashboard user and returns stdout, stderr, and exit status. Use it for ordinary local tasks not covered by a dedicated tool. Commands that appear to change system state require confirmation.

                

                
The agent can inspect and operate on the local PC through these tools, but it cannot visually see your screen, automatically become root, or guarantee that every command is available. Shell approval checks are heuristic, so keep the dashboard private and review proposed commands.
